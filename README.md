# 🎬 MovieIQ
## Predictive Analytics on Film Success using Machine Learning

---

## 📌 Project Overview

MovieIQ is a Machine Learning based web application that predicts whether a movie is likely to be successful based on its features such as Budget, Popularity, Runtime, and Vote Average.

The application also provides an interactive dashboard for data analysis, statistical testing, prediction, and feature importance visualization.

---

## 🎯 Objectives

- Predict movie success using Machine Learning.
- Perform Exploratory Data Analysis (EDA).
- Visualize important movie statistics.
- Display feature importance.
- Build an interactive Streamlit dashboard.

---

## 🚀 Features

### 🏠 Home
- Project Overview
- Dataset Summary
- Key Metrics
- Total Movies
- Successful Movies
- Average Rating

### 📊 EDA Dashboard
- Genre Filter
- Vote Average Filter
- Dataset Preview
- Download Filtered Dataset
- Budget vs Revenue Scatter Plot
- Success Distribution
- Popularity Distribution
- Runtime Distribution
- Vote Average Distribution
- Correlation Heatmap

### 📈 Statistical Tests
- T-Test Results
- Chi-Square Test Results
- Statistical Interpretation

### 🎯 Prediction
Users can enter:

- Budget
- Popularity
- Runtime
- Vote Average

The trained Random Forest model predicts whether the movie is likely to be successful.

### ⭐ Feature Importance
Displays:
- Feature Importance Table
- Feature Importance Bar Chart
